The terminal tools over the pseudo-terminal (`crates/exec/src/terminal.rs`, `sanitize.rs`, `terminals.rs`, `terminal_tools.rs`; TC-PORT-TERM-15..40, TC-CLI-TERM-1), closing the clause three earlier notes in this lane had all named as next. The decision worth recording is that readiness is *announced* rather than inferred: upstream watches its terminal for silence and probes whether the foreground process is blocked reading, then decides a command has probably finished, while the shell here is told to print an OSC 133 marker before every prompt - so a send settles when the shell says the command is over, and the marker carries `$?`, which silence never could. Upstream's two guesses stay as the fallbacks they should have been, for a program that prints no marker at all, and both are named in the answer so a caller knows which it got. Three defects and one hazard came out of writing it, all in this slice's own code: an interrupted command still owes a prompt, and the marker arrived after the send had answered - settling the *next* send instantly, with an empty viewport, reporting a command that never ran as finished - so the interrupt path now waits for the prompt it just caused; a background job started in a terminal is in its own process group under job control, so closing the session by killing the leader's group left a `sleep` running, and closing now sweeps the terminal's whole session through `/proc`; a session nobody holds any more could not hang up, because the read task keeps the master open until the child ends and the child is waiting for input that will never come, so `Drop` sends `SIGHUP`; and the viewport carried the caller's own command twice, once from the terminal's echo and once from the shell redrawing the line, which `stty -echo` at startup ends. The owner-scoped registry is enforced now rather than retrofitted - an `Owner` is an opaque name the composition chooses, because tetanus sessions have no agent identity yet, and the engine gives each session its own registry - since the day a sub-agent appears is the day two agents share one and neither can tell. Registering the six tools in `crates/cli/src/main.rs` cost 432 structural points for forty-five lines, exactly what `CONTRIBUTING.md` warns about, so the binary's whole tool composition moved to `crates/cli/src/tools.rs`. What stays out is named in `docs/parity-updates/shell-terminal-tools.md`: background jobs and their store, spill files, the presentation half of a live terminal card, a screen model for programs that draw with cursor movement, and a prompt marker for a PowerShell that `-NoProfile` will not let us configure.
