PowerShell terminals announce their prompts, and the terminal answers what programs ask it (`crates/exec/src/screen.rs`, `backend.rs`; TC-PORT-SCREEN-8, TC-PORT-TERM-46). The row asked only for the marker; closing it needed something the row had not named. A terminal is not only a screen - a program *asks* it things and blocks on the answer, and PowerShell's line editor asks for the cursor position before it prints its first prompt, so against a terminal that never replies pwsh does not start at all: it prints a PSReadLine bug report and gives up. That was measured against a bare pseudo-terminal and against `script`, which fails identically, before a line was written. The screen answers, because it is the only thing here that knows where the cursor is - position, device status and both device-attribute forms - and it answers truthfully rather than flatteringly, claiming a VT100 with the advanced video option, which is the honest floor for what it models. `Screen::feed` is `#[must_use]` because an unanswered question is a hung program; the lint immediately caught this lane's own cases, which now assert that ordinary output asks for nothing back. The marker itself is *typed*: bash gets one through `PROMPT_COMMAND`, an environment variable handed over before the shell starts, while a PowerShell prompt is a function whose only home is the `$PROFILE` that `-NoProfile` skips - so `terminal_setup`, the seam bash already uses for `stty -echo`, types the definition once the REPL is ready. A pwsh send now settles as `stdin_read` carrying `$LASTEXITCODE` or `$?`, where before it settled on silence after three seconds and reported nothing. Verified the way #241's author verified his fix, and for the same reason - CI ships a PowerShell and this fleet's boxes do not: a 7.4.6 tarball on `PATH`, with the whole `crates/exec` suite run both ways, 127 cases with pwsh and 127 without. One clause replaces the closed one: PSReadLine repaints the edited line several times per send, so a pwsh viewport carries its command more than once, and the honest fix is a per-send screen delta rather than trimming repeated text.
