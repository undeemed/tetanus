Closed the rest of the `shell/*`, `terminal/*`, `subprocess/*` Gap column: spill, the piped seam, session-owned terminals, and the collectable half of background work (TC-PORT-PROC-19..26, TC-PORT-SHELL-20, TC-PORT-TERM-41, TC-CLI-SHELL-4). Three of the four were waiting on something that has since arrived, which is the argument for sweeping a row rather than re-deriving it: spill was blocked on a storage policy and the storage lane wrote one, so this put the producer on the other end - and the producer is the only one who can, because a bounded capture drops its beginning while the command runs and a policy above the seam would file the tail and call it the output; the artifact is opened on the first overflow and never before, so a command whose output fits touches no filesystem, and because the buffer still holds everything at that instant what lands on disk is the complete stream. Piped stdio was waiting on a first consumer, and `crates/mcp` arrived by spawning its own child - which killed the server and left a server's own helpers running - so the seam closed a leak rather than tidying a duplicate, and MCP's suite is green over it unchanged. Owner-scoping was waiting on "a session having an owner", which turned out to mean the composition had no way to be told which session it was building for: `SessionTools` now carries the session's id and the directory of its journal, so a terminal is owned by the session that opened it and a spilled build log lands where a reader is already looking. Background jobs are answered in two halves rather than deferred whole: on a terminal the session is already the collection point, so `wait_ms` makes "start it and come back" a thing a model asks for (silence deliberately does not settle a short wait, and zero is refused because a send that waited no time would report an empty viewport as no output), while `run_in_background` for the one-shot `shell` really does need the `jobs/*` store - a one-shot's group is swept when its call returns - and the note names the three things that store must offer rather than building a second one here. What remains is a screen model for programs that draw with cursor movement, a PowerShell prompt marker that `-NoProfile` will not let us configure, and a Windows host; `docs/parity-updates/shell-row-closed.md` says what each would take.
