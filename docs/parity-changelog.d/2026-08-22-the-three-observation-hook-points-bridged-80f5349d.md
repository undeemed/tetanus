The three observation hook points bridged (`crates/hooks/src/bridge.rs`, TC-HOOK-WATCH-1..10), completing all five. None of `SessionStart`, `UserPromptSubmit` or `Stop` carries a permission answer, so none can refuse a tool call - but two can still change what happens, and which two is what decides where each registers. `UserPromptSubmit` may add context to a prompt or refuse it outright, and `agent/pre-step`'s decision is exactly those two options, so it registers there; it fires only on the first step's claim, because a later claim is the loop's own bookkeeping and running a prompt hook over it would tell the hook a person said something they never typed. `Stop` may ask that the turn *not* end, which is the veto `agent/turn-stopping` already takes. `Stop` is also the one inverted point in either dialect: everywhere else a hook's `continue: false` asks the turn to halt, but here the turn is already ending, so the same field is the only way a hook can ask for more work - reading it the usual way round would turn "do not stop yet" into "stop", the exact opposite of what a deployment configured. `SessionStart` can only observe, and that is recorded as a gap rather than approximated: its `additionalContext` is decoded and returned but has no sink, because the only one is the turn's queue and a session has not started a turn when the point fires; a hook whose context was silently dropped would be worse than one that was never run. The port found and fixed a real defect: the payload context is built once when a bridge is composed, so Codex's turn-scoped `turn_id` served that construction-time value, and every hook would have seen every event as belonging to one turn - a hook correlating a `PreToolUse` with the `Stop` that followed would have paired them across unrelated turns. Four mutations; three were caught immediately and the fourth exposed a weak assertion of this port's own, a wordless refusal checked only for presence, so an empty string would have reached a person as a blank rejection reading like a harness bug rather than a configured policy; the case now pins the words.
