Swept the `shell/*`/`terminal/*`/`subprocess/*`, `sandbox/*` and `fs/*` rows against the code that now exists, closed the one gap clause that was still buildable, and rewrote the three rows to say what is true. The closure is the per-call escalation stamp (TC-PORT-SANDBOX-28..31), which both earlier notes had named as the remaining follow-up: upstream's escalation is an approval protocol over a policy, and both halves already existed here, so it is `Policy::widened_to` meeting `tetanus_turn::approval` rather than a new mechanism. The `shell` tool declares `Permission::Ask` for a call carrying `sandbox_permissions`, so the question goes through the engine's existing gate and is audited as the same asked/decided pair as every other decision, with the command, both modes and the model's own sentence in the reason; the grant applies to one call and the wider executor is dropped with it, because a cached one is a grant that outlives the question that bought it; a malformed request - unpaired, unknown mode, or not actually wider - is refused in words with no question put at all, since an unanswerable question is worse for the person answering than a refusal; and the two arguments are advertised only where a wider mode exists to ask for. Writing the cases caught one passing for the wrong reason: the refusal case first asked for `workspace-full-access`, which is not a mode, so validation refused it before the answerer ever saw it, and it now asserts the audit pair to prove which of the two said no. Everything else in the three rows is genuinely blocked on something nameable rather than merely undone - a PTY dependency, a job store, a storage policy for spill files, a first consumer for raw piped stdio, a Windows or macOS host to prove a backend on, a container for read confinement - and each clause now says what it waits on, so the slice that lands that thing can close it instead of a future sweep re-deriving why it is open. The `fs/*` row is clear of everything this lane owned: its kernel-sandbox clause is served, and what remains is the fs lane's own list.
