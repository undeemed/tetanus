Running one external command implemented (`crates/turn/src/process.rs`) and ported (TC-PORT-PROC-1..10), opening the `subprocess/*` row. It is the primitive under a shell tool, an out-of-process hook, an MCP server on stdio and a subagent driver, and it deliberately registers nothing, so nothing a model says reaches it yet - the model-facing shell tool is sequenced after the approval gate, not before it. The environment design is inverted from upstream on purpose: Node hands a child `process.env`, so upstream inherits and scrubs a denylist, while a denylist has to recognise every secret a deployment might have set and the one it misses is handed to a program a model chose. Here a child gets what the caller listed, and `inherit_env` is the opt-in whose name is the warning. Two more rules: output is bounded and the bound keeps the tail, because the end of a stream is where the error and the summary are; and a timeout is an outcome rather than a failure, so what the command printed before it was killed still comes back. The termination gap is stated rather than implied - this kills the child it started and not its process group, so grandchildren survive, and closing that needs a platform dependency the workspace does not have.
