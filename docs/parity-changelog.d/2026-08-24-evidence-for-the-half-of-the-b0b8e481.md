Evidence for the half of the signal fix that shipped without any (TC-PORT-TERM-48). `signals::reset_for_child` empties a child's signal mask as well as resetting its dispositions, because a *blocked* signal is inherited across `exec` exactly as an ignored one is - and only the dispositions had a case. Blocking is as ordinary a thing to inherit as ignoring: a supervisor that blocks while it forks, a process started from inside a handler, a runtime that masks during startup. The visible failure is identical and just as quiet - `killpg` reports success, the command sleeps on, and a model that asked for its runaway command to stop is told that it stopped. The new case blocks `SIGINT` in the test process rather than ignoring it, and asserts a terminal command still dies; with only the mask half of the fix removed it fails in 11.2s while the disposition case still passes, which is what shows the two cases measure different halves rather than the same one twice. The two hold a mutex against each other, since each mutates process-wide signal state and cargo runs a file's tests in parallel.
