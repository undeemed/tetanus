Workspace instructions implemented (`crates/turn/src/instructions.rs`, TC-PORT-INSTR-1..12), opening the `context/*` row. A repository that keeps an `AGENTS.md` is telling whoever works in it how to work there, and an agent that never reads one re-learns the same conventions every session. Files are read from the project root down to the working directory, so nearer guidance comes last and the preamble says so in words too - ordering alone is a convention a model may or may not honour. The search stops at a `.git` marker, because reading above it pulls a parent checkout's or a home directory's conventions into a project that never asked for them. The security-relevant rule is that content is escaped before it is framed: instruction files come from whoever can open a pull request, the block is delimited, and a file containing that delimiter's closing tag would otherwise end the block early and have everything after it read as harness instruction rather than project guidance. A candidate is a file name and never a path, so a settings document cannot point the search outside the project it is bounded to; the budget drops whole files rather than cutting one, because a truncated instruction can invert its own meaning.
